# DFB-Pokal Männer 2024/25
Source: DFB Spielordnung, version 1 June 2024, section 2.1.1: https://www.dfb.de/fileadmin/_dfbdam/304263-Heft_04_Spielordnung_Schiedsrichterordnung_20240601.pdf
Season-specific confirmation: https://www.dfb.de/news/detail/olympiasiegerin-greinacher-lost-zweite-pokalrunde-aus-263769
Round 1: two pots; newly promoted second-tier clubs and previous second-tier 15th plus 16th if retained via playoff belong in A despite league status. Round 2: pots by current season status. Cross-pot fixtures have A home rights; remaining same-pot fixtures use first drawn. Rounds 3–5: one pot, amateur home priority against licensed clubs, otherwise first drawn. Final: designated venue, excluded from draw model. Uniform random order assumed; marginal probabilities only, no independence claim across clubs. Pot membership and amateur status are explicit inputs, never inferred from score order or venue. No historical draw records certified by this implementation. Scope restricted to 2024/25.
