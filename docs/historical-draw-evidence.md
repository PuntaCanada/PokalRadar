# Historical draw evidence
Scope: second round of men's DFB-Pokal 2024/25 only. Independently matched the 16 published draw pairings against the existing match IDs and checked each team's league against the pre-draw DFB FAQ. Both sources dated 1 September 2024. Sources are recorded per match. No venue inferred. No source text copied. All 32 existing league assignments agree; no missing tiers filled in this round. Model assumes uniform random draws under the published procedure; opponent tier is ordinal, not a strength rating. Home deltas are single-round observations, not career rankings. No public page or existing dataset changed yet.
