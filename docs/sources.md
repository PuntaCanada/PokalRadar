# Sources and publication limits
OpenFootball deutschland: https://github.com/openfootball/deutschland — upstream describes football data as public domain. Snapshots under data/sources/openfootball, seasons 2018–2024. Preserve original filenames and line provenance. Exact-name league matches only; unresolved aliases remain unknown. No historical draw rules or stadium data certified. OpenLigaDB ODbL 1.0 is a prospective separate adapter; no OpenLigaDB data included. Do not infer formal home rights from listed home team. Structural validation does not establish independent factual verification. Awarded results excluded from played goals. Final treated neutral by project convention. Nonfinal neutrality unknown. No current season yet. Source snapshots are not independently audited. No official logos.
